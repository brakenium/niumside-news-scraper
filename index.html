How it works

A GitHub Actions workflow retrieves the PlanetSide 2 patch-notes page every 15 minutes and extracts the news and patch-note feed objects embedded in the page.

The current feed files contain the entries currently exposed by PlanetSide 2. The archive files accumulate every previously discovered entry, so entries remain available after they disappear from the current feed.

The archived entries preserve the JSON objects returned by PlanetSide 2 without reducing them to a custom schema.
